# Schedular App

This project is a calendar application built with JavaFX for managing schedules and events. It showcases various features with functional implementations using the MVC (Model-View-Controller) architecture pattern.

<img width="892" height="558" alt="Scheduler App Screenshot" src="https://github.com/user-attachments/assets/2c58412c-de78-4960-9b0c-c977e27f10ad" />

## Features

* Interactive Calendar View
* Event Management (Create, Edit, Delete)
* Recurring Events (Daily, Weekly, Monthly)
* Smart Conflict Detection
* Customizable Reminders
* Event Search Functionality
* Real-time Notifications
* Event Statistics
* Backup & Restore (CSV)

## Technologies

* **JavaFX** - UI framework
* **Java** - Programming language
* **CSS** - Styling
* **Ikonli** - Icon library (Bootstrap Icons)
* **CSV** - Data storage
