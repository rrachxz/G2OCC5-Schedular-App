## ✨ Key Features

### 📆 **Interactive Calendar View**
Navigate through months with an intuitive visual calendar that displays all your events at a glance.

### 🎯 **Smart Event Management**
Create, edit, and delete events with customizable details including title, description, date, and time.

### ⏰ **Flexible Reminders**
Set custom reminder notifications:
- 15 minutes before
- 30 minutes before
- 1 hour before
- 1 day before

### 🔄 **Recurring Events**
Schedule repeating events with daily, weekly, or monthly patterns.

### ⚠️ **Conflict Detection**
Automatically alerts you when events overlap, preventing double-booking.

### 🔍 **Quick Search**
Find events instantly by keyword or date.

### 🔔 **Real-time Notifications**
Get timely alerts for upcoming events based on your reminder preferences.

### 📊 **Event Statistics**
View insights about your schedule:
- Upcoming events count
- Weekly overview
- Busiest days analysis

### 💾 **Backup & Restore**
Export and import your calendar data with CSV backup functionality.
